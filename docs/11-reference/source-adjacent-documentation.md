# Source-Adjacent Documentation

Some documentation stays beside the code it describes.

| Area             | Paths                                                                                                     |
| ---------------- | --------------------------------------------------------------------------------------------------------- |
| Database         | `Garazyk/Sources/Database/README.md`, `Garazyk/Sources/Database/ARCHITECTURE.md`                          |
| Admin UI         | `Garazyk/Sources/Admin/`, `Garazyk/Sources/AdminUIServer/Assets/`                                         |
| HTTP and parsing | `Garazyk/docs-site/src/content/docs/core-server/`, `Garazyk/docs-site/src/content/docs/advanced-parsing/` |
| AT Protocol      | `Garazyk/docs-site/src/content/docs/atproto/`                                                             |
| Authentication   | `Garazyk/docs-site/src/content/docs/auth/`                                                                |
| Federation       | `Garazyk/docs-site/src/content/docs/federation/`                                                          |
| Test fixtures    | `Garazyk/Tests/fixtures/`, `Garazyk/Tests/plc_e2e/`                                                       |
| Scenario runner  | `scripts/scenarios/`                                                                                      |
| PLC tools        | `scripts/plc/`                                                                                            |

Update these files with the module or tool they describe. The
[documentation map](documentation-map.md) lists the main entry points.
